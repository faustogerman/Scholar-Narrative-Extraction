# Scholar Narrative Extraction

A demo that extracts a coherent **narrative** from a scholarly corpus in response to a natural-language query, then visualizes
and summarizes it.

```
query → LLM decomposition → top-k retrieval → endpoint selection
      → narrative extraction (max-capacity path) → landscape viz → summary
```

The system decomposes a query into a *source* and *target* concept, retrieves
candidate documents, builds a coherence graph over them, and finds the
maximum-capacity (widest) path connecting the two endpoints. It then projects
the corpus to 2-D (UMAP + HDBSCAN) to show where the narrative travels, and
synthesizes a short, in-text-cited summary.

## Datasets

Two corpora are bundled under `Data/`, each loaded from a single
`text_data.csv`:

| Dataset   | Documents | Constraints supported            |
|-----------|-----------|----------------------------------|
| **VisPub**  | 3,549 IEEE Visualization papers (1990–2022) | temporal + citation PageRank |
| **Physics** | 29,555 arXiv hep-th abstracts               | semantic only                |

Document embeddings are pre-computed so no local embedding model is required,
but the embedding files are large and are **not** included — you generate them
once with [`extract_embeddings.py`](extract_embeddings.py) (see below). Expected
layout:

```
Data/
├── VisPubData/
│   ├── text_data.csv              # metadata (title, abstract, year, DOI, references)
│   └── embed_data-gpt4.pickle     # generated by extract_embeddings.py
└── cit-HepTh/
    ├── text_data.csv              # metadata (title, abstract, date)
    └── embeddings/
        └── embed_data-gpt4.pickle # generated by extract_embeddings.py
```

Each `text_data.csv` is aligned 1-to-1 with its embeddings pickle (same row
order), so document *i* in the CSV corresponds to embedding row *i*.

### Generating the embeddings

With `OPENAI_API_KEY` configured (see [Configuration](#configuration)), run:

```bash
python extract_embeddings.py            # both datasets
python extract_embeddings.py --dataset vispub   # a single dataset
python extract_embeddings.py --force    # overwrite existing pickles
```

This embeds `"<title>; <abstract>"` for every document with OpenAI
`text-embedding-3-small` and writes each `embed_data-gpt4.pickle` in the layout
above. It skips datasets whose pickle already exists unless `--force` is given.

## Installation

Requires Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate        # on Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

> `numpy<2` is pinned for compatibility with `umap-learn` and `hdbscan`.

## Configuration

Live OpenAI calls are used for query embedding, endpoint embeddings, query
decomposition, and the summary. (Retrieval, graph construction, path finding,
and the landscape projection all run locally from the cached embeddings.)

Copy the example env file and add your key:

```bash
cp .env.example .env
# then edit .env and set OPENAI_API_KEY=...
```

Alternatively, export it in your shell:

```bash
export OPENAI_API_KEY=your-openai-api-key-here
```

## Running

Make sure the embeddings have been generated (see
[Generating the embeddings](#generating-the-embeddings)), then start the app:

```bash
python app.py
```

This launches a Gradio web app (printed URL, typically http://127.0.0.1:7860).
Pick a dataset, choose or type a query, optionally toggle the temporal /
citation constraints (VisPub only), and click **Extract narrative**.

## Project layout

| File               | Purpose                                                        |
|--------------------|----------------------------------------------------------------|
| `app.py`           | Gradio UI and pipeline orchestration                           |
| `pipeline.py`      | Retrieval, endpoint selection, graph + narrative extraction    |
| `demo_datasets.py` | Dataset definitions and loaders                                |
| `viz.py`           | Altair landscape / narrative-path visualization                |

To point the app at data in a different location, set `NARRATIVE_DATA_DIR` to a
folder containing `VisPubData/` and `cit-HepTh/`.
